# Just a note

Просто заметки. Скачал, записал, закрыл. Когда нужно — открыл, прочитал и вышел. Проще некуда. Приложению не нужны миллионы лишних функций, которыми никто не пользуется. Оно весит всего 5 МБ, работает моментально и делает ровно то, для чего создано. 

# О данных

Вся информация хранится в простом .json формате — её легко контролировать. Если вы случайно удалите заметку в интерфейсе, её всё равно можно восстановить из файла, так как история не очищается автоматически. 

Перенос данных тоже устроен максимально прозрачно. Достаточно скопировать .json из папки main_data на флешку (даже при активном использовании файл весит не больше 100 МБ) и перенести его на другой компьютер, где установлен Just-a-Note. Никаких сложных облаков и привязок — ваши заметки всегда остаются вашими.
