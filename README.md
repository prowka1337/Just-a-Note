# Just-a-Note
Просто заметки. Скачал - добавил заметку, вышел. Далее зашел, прочитал заметку, вышел. Проще некуда. Мне лично удобней пользоваться программой которая весит 5 МБ, максимально проста и удобна, чем заметками с миллионными охватами, в которых слишком много ненужных ЛИЧНО ДЛЯ МЕНЯ фичей.

# О ДАННЫХ
Данные сохраняются в .json файл, то есть их легко вытащить. Также, из этого же .json можно прочитать старую заметку, если вы ее удалили случайно (данные не очищаются никогда).
Вы можете перетащить .json файл из папки main_data на флешку (он весит даже при пике максимум 100 МБ), скачать на другой компьютер Just-a-Note и туда поместить файл user_notes. Таким образом, программа становится удобней.
